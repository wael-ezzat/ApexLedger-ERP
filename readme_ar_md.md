## ⚙️ المميزات والخصائص المعمارية البارزة

- **دعم ثنائي اللغة (Localization Ready):** تصميم متكامل يعتمد على أعمدة مزدوجة (الإنجليزية والعربية) للجداول الرئيسية مثل المنتجات، الفئات، المستودعات، والأدوار.
- **أتمتة المخزون الذكية (Smart Inventory Triggers):** مشغلات خلفية (`DML Triggers`) متقدمة تقوم بتحديث أرصدة المستودعات فورياً وحساب أسعار التكلفة تلقائياً مع كل عملية بيع أو شراء، مع حماية كاملة ضد الرصيد السلبي (متوفرة في الحزمة التجارية).
- **إدارة الصلاحيات والأمان (RBAC):** نظام صلاحيات متطور يعتمد على الأدوار (أدوار النظام والمستخدمين والصلاحيات التفصيلية).
- **سجل تدقيق العمليات (Audit Logging):** نظام تتبع إداري يسجل بدقة عمليات الإضافة، التعديل، والحذف (`INSERT, UPDATE, DELETE`) مع حفظ بيانات المستخدم وسياق التعديل.
- **المحاسبة المالية ذات القيد المزدوج:** شجرة حسابات هرمية مرنة تدعم قيود اليومية المتوازنة بدقة تامة.

## 📂 محتويات قاعدة البيانات (21 جدولاً أساسياً)

تنقسم البنية المعمارية للمشروع إلى 4 وحدات رئيسية متكاملة:

1. **وحدة الهوية والأمان (RBAC & Audit):**  
   - `Users`, `Roles`, `Permissions`, `RolePermissions`, `UserRoles`, `AuditLogs`
2. **وحدة الخدمات اللوجستية والمخزون:**  
   - `Branches`, `Warehouses`, `Categories`, `ProductUnits`, `Products`, `ProductStock`
3. **وحدة العمليات التجارية (المبيعات والمشتريات):**  
   - `Suppliers`, `Customers`, `PurchaseInvoices`, `PurchaseInvoiceDetails`, `SalesInvoices`, `SalesInvoiceDetails`
4. **وحدة الحسابات العامة (General Ledger):**  
   - `Accounts`, `JournalEntries`, `JournalEntryLines`

## 🛠️ دليل البدء السريع والتثبيت

1. افتح أداة **SQL Server Management Studio (SSMS)** واتصل بخادم قاعدة البيانات الخاص بك (SQL Server 2019 أو أحدث).
2. أنشئ قاعدة بيانات فارغة جديدة.
3. افتح نافذة استعلام جديدة (`New Query`)، والصق محتوى ملف السكريبت الموحد (`ApexLedgerERP_DB.sql`).
4. اضغط على زر **Execute** (أو مفتاح `F5`) لتنفيذ السكريبت بالكامل.
5. تأكد من ظهور رسالة النجاح في نافذة النتائج:  
   `SUCCESS: ApexLedger ERP Base Schema Deployed Successfully on SQL Server!`
