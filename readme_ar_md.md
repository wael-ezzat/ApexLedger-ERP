# 🏛️ نظام قواعد بيانات ApexLedger ERP (الإصدار 1.2.0)
### الأساس التقني المتكامل لأنظمة تخطيط موارد المؤسسات (ERP) على Microsoft SQL Server

> **ApexLedger ERP** هو هيكل قاعدة بيانات علائقي (Relational Database Schema) جاهز للإنتاج ومُحسّن بعناية فائقة، مخصص لمهندسي البرمجيات والشركات التقنية لتسريع بناء وتطوير أنظمة الـ ERP والحلول المؤسسية الحديثة على **Microsoft SQL Server 2019 والإصدارات الأحدث** دون إهدار أشهر في تصميم قواعد البيانات من الصفر.

---

## 🎯 لماذا تم بناء هذا المشروع؟
يبني معظم المطورين والفرق التقنية هيكل قواعد البيانات لتطبيقات الـ ERP في كل مشروع جديد من الصفر، مما يستهلك وقتاً طويلاً في معالجة القواعد المعقدة للمخزون، توازن القيود المحاسبية، وتأمين الصلاحيات. 
يوفر لك **ApexLedger ERP** بنية أساسية صلبة، نظيفة، ومختبرة بنسبة 100% لتنطلق فوراً في بناء واجهات وبرمجيات التطبيق الخاص بك.

---

## ⚙️ المميزات والخصائص المعمارية البارزة

- **دعم ثنائي اللغة (Localization Ready):** تصميم متكامل يعتمد على أعمدة مزدوجة (الإنجليزية والعربية) للجداول الرئيسية مثل المنتجات، الفئات، المستودعات، والأدوار.
- **أتمتة المخزون الذكية (Smart Inventory Triggers):** مشغلات خلفية (`DML Triggers`) متقدمة تقوم بتحديث أرصدة المستودعات فورياً وحساب أسعار التكلفة تلقائياً مع كل عملية بيع أو شراء، مع حماية كاملة ضد الرصيد السلبي.
- **إدارة الصلاحيات والأمان (RBAC):** نظام صلاحيات متطور يعتمد على الأدوار (أدوار النظام والمستخدمين والصلاحيات التفصيلية).
- **سجل تدقيق العمليات (Audit Logging):** نظام تتبع إداري يسجل بدقة عمليات الإضافة، التعديل، والحذف (`INSERT, UPDATE, DELETE`) مع حفظ بيانات المستخدم وسياق التعديل.
- **المحاسبة المالية ذات القيد المزدوج:** شجرة حسابات هرمية مرنة تدعم قيود اليومية المتوازنة بدقة تامة.

## 📂 محتويات قاعدة البيانات (21 جدولاً أساسياً)

تنقسم البنية المعمارية للمشروع إلى 4 وحدات رئيسية متكاملة:

1. **وحدة الهوية والأمان (RBAC & Audit):** 
   - `Users`, `Roles`, `Permissions`, `RolePermissions`, `UserRoles`, `AuditLogs`
2. **وحدة الخدمات اللوجستية والمخزون:** 
   - `Branches`, `Warehouses`, `Categories`, `ProductUnits`, `Products`, `ProductStock`
3. **وحدة العمليات التجارية (المبيعات والمشتريات):** 
   - `Suppliers`, `Customers`, `PurchaseInvoices`, `PurchaseInvoiceDetails`, `SalesInvoices`, `SalesInvoiceDetails`
4. **وحدة الحسابات العامة (General Ledger):** 
   - `Accounts`, `JournalEntries`, `JournalEntryLines`

## 🧪 نتائج الاختبارات والجودة (100% نجاح)

تم إخضاع هيكل القاعدة لاختبارات صارمة وشاملة وتجاوزها بنجاح تام (48/48 اختبار):
* **15/15** اختبارات وظيفية (Functional Tests) لتدفقات البيع والشراء.
* **12/12** اختبارات صلابة وتحمل (Hardening Tests).
* **21/21** اختبارات أمان وتكامل البيانات (Security & Integrity Tests).
* اختبارات التثبيت النظيف (Clean Installation) وتداخل العمليات (SQL Server Concurrency).

## 🛠️ دليل البدء السريع والتثبيت

1. افتح أداة **SQL Server Management Studio (SSMS)** واتصل بخادم قاعدة البيانات الخاص بك (SQL Server 2019 أو أحدث).
2. أنشئ قاعدة بيانات فارغة جديدة.
3. افتح نافذة استعلام جديدة (`New Query`)، والصق محتوى ملف السكريبت الموحد (`ApexLedgerERP_DB.sql`).
4. اضغط على زر **Execute** (أو مفتاح `F5`) لتنفيذ السكريبت بالكامل.
5. تأكد من ظهور رسالة النجاح في نافذة النتائج:  
   `SUCCESS: ApexLedger ERP Database Deployed Successfully on SQL 2019!`

## 📄 ملاحظة ترميز النصوص (Encoding)
يحتوي السكريبت على نصوص لغة عربية باستخدام أنواع بيانات `NVARCHAR`. لذلك، تأكد دائماً من حفظ ملف السكريبت بصيغة ترميز **UTF-8 with BOM** لمنع أي تلف في الحروف العربية عند تشغيله على خوادم مختلفة.
